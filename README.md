## How I approach a problem

- GPU-accelerated pipelines over CPU-heavy ones — TensorRT and DeepStream first, Python where it earns its keep
- Modular architectures that separate detection from recognition, so either half can be swapped without rewriting the other
- Hybrid systems — DeepStream carrying frames, Python services carrying the business logic, MQTT / REST between them
- Real-world production deployments over lab prototypes: latency, throughput, and uptime targets are the specification, not paper-benchmark numbers
